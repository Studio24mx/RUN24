# RUN24 — Signalpunk Visual Slice Implementation

Status: first playable art-direction pass implemented.

## What is now represented in-game
- RUNNER 24: bone-mask silhouette, dark cutout body, cochineal scarf, jade CORE and gold weapon core.
- XOLO: spectral xolo companion with bone markings, jade spirit flame and follow animation.
- Signal Husk: walker enemy visual identity.
- Vigilante: turret/shrine-drone visual identity.
- Centinela: flying soul-router visual identity.
- THE IDOL: first boss reworked as a multi-armed broadcast saint with bone mask, signal halo and exposed CORE.
- Environment: obsidian architecture, layered brutalist skyline, cochineal signal suns, signal towers and glyph markers.
- Platforms: darker collision surfaces with jade readability edges.
- HUD: obsidian top/bottom frames, jade/cochineal accents, cempasuchil CORE, THE IDOL boss treatment.
- Combat FX palette: player projectiles = jade, enemy projectiles = cochineal, specials = cempasuchil.
- Pickups: heal = jade, rapid = cempasuchil, spread = cochineal.
- Hazards: cochineal.

## What this pass is
A real in-engine style test using controlled vector-like geometry and procedural drawing. It proves silhouette, palette, hierarchy and world cohesion while preserving gameplay.

## What this pass is not
It is not final production illustration. After gameplay testing confirms readability, replace selected procedural forms with authored Krita/Inkscape assets while preserving the same silhouette and palette logic.
